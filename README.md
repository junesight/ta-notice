# 자동차보험 환자 안내문 작성기

한의원용 자동차보험 환자 맞춤 치료 안내문 자동 생성 및 인쇄 웹 애플리케이션입니다.

## 주요 기능
1. **간편한 입력**: 환자명과 사고 발생일 6자리(예: `261030`)만 입력하면 자동으로 날짜를 계산합니다.
2. **법정 치료 가능 기간 자동 계산**:
   - D+20 (사고 발생일로부터 3주까지): 매일 치료 가능
   - D+76 (사고 발생일로부터 11주까지): 주 3회 치료 가능
   - D+181 (사고 발생일로부터 26주까지): 주 2회 치료 가능
   - D+182 (사고 발생일로부터 26주 이후): 주 1회 치료 가능
   - 주 치료 기준 요일 범위(사고 요일 ~ 사고 전날 요일) 자동 계산
3. **자배원 8주 초과 장기치료 검토 서류 제출 기한**:
   - D+49 (사고 발생일 기준 7주 이내) 자동 산출
4. **엑셀 원본 양식 100% 반영 & A4 1장 인쇄 최적화**:
   - 브라우저 인쇄(`Ctrl+P` 또는 인쇄 버튼) 시 화면 입력창은 사라지고 A4 1장에 꼭 맞게 출력됩니다.
   - 단축키: Enter 키로 바로 인쇄 대화상자 호출 가능.
   - 텍스트 복사 버튼 지원 (차트 전자의무기록(EMR) 메모용 등).

## 실행 방법
`index.html` 파일을 크롬, 엣지(Edge) 등 최신 웹 브라우저로 더블 클릭하여 바로 열면 별도 서버 없이 즉시 작동합니다.
